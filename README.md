•	Суть: Десктопное приложение на Python (Tkinter + Pandas) для учета научно-исследовательских геофизических рейсов.
•	Интерфейс: Многовкладочный (Tab-based) с цветовым выделением кнопок.
•	БД: Файл voyage_data.xlsx из 20 полей. Числовые поля: № п/п, Год, № рейса, № этапа рейса, Номер диска, Инвентарный номер диска.
•	Особые условия кода: Обязательна проверка типов передаваемых параметров в процедурах (isinstance). 
Справочники сделаны в виде списков. Поля не обязательны к заполнению. Все повторяющиеся функции вынесены в helpers.py.
•	Текущий статус: Просмотр, поиск, редактирование, удаление, создание по шаблону и бекап полностью работают.

Менеджер информации о научно-исследовательских рейсах (Cruise-data)
Десктопное приложение на Python с графическим интерфейсом (Tkinter), предназначенное для комплексного учета, поиска, редактирования 
и архивации данных научно-исследовательских геофизических рейсов. 
Вся информация сохраняется локально в файлы таблиц Excel.

📋 Основные возможности программы
- Управление данными: Просмотр, добавление, редактирование, удаление записей, а также быстрое создание новых рейсов по шаблону.
- Многовкладочный интерфейс: Разделение работы с основными и побочными (суб-данными) таблицами на независимых цветных вкладках.
- Гибкий поиск: Система фильтрации рейсов по ключевым полям.
- Безопасность данных: Автоматическая и ручная система резервного копирования (бэкап) файлов базы данных с возможностью настройки параметров архивации.

 🛠 Архитектура проекта и файл main.py
 Программа построена по модульному принципу: 
 main.py отвечает за графический интерфейс (GUI) и логику окон, а 
 повторяющиеся операции вынесены в helpers.py.
 
 Ключевые методы классов и функции в main.py1. 
 
 1. Класс главного окна (Основной интерфейс)

  __init__(self, root) — Инициализирует главное окно приложения, настраивает многовкладочный интерфейс (Tab-based notebook) 
 и задает цветовую палитру для кнопок и панелей.
 
 create_widgets(self) — Формирует визуальные элементы управления: таблицы вывода (Treeview), текстовые поля ввода, 
 поисковые строки и кнопки управления.
 
 refresh_table_data(self) — Считывает актуальные данные из Excel-файлов с помощью Pandas и обновляет их отображение на экране пользователя.
 
 2. Логика работы с записями (CRUD и Шаблоны)
 add_record(self) — Открывает диалоговое окно для внесения нового рейса. Проверяет корректность типов данных перед отправкой в файл.
 edit_record(self) — Подгружает данные выбранного из таблицы рейса в форму для их последующего изменения и перезаписи.
 delete_record(self) — Безвозвратно удаляет выбранную строку из текущей таблицы после подтверждения пользователем.
 create_by_template(self) — Копирует параметры существующего (выбранного) рейса, позволяя быстро создать на его основе новую запись без ручного ввода повторяющихся данных.
 
 3. Поиск и Фильтрация
 search_records(self) — Динамически фильтрует строки в таблице на основе введенных пользователем данных (например, поиск по номеру рейса, году или инвентарному номеру).
 reset_search(self) — Сбрасывает все активные фильтры поиска и возвращает таблицу к исходному полному списку записей.
 
 4. Архивация и Бэкап
create_backup(self) — Создает резервную копию рабочих таблиц Excel.
check_archive_deadlines(self) — Фоновая процедура, проверяющая установленные лимиты времени (дни до архивации). 
Извещает пользователя о необходимости заархивировать старые данные.

📊 Структура данных и базы данных

Программа использует две реляционные таблицы в формате Excel (.xlsx), выступающие в роли локальной базы данных:
voyage_data.xlsx (Основная таблица) — содержит 20 информационных полей для описания экспедиций. Поля не являются обязательными для заполнения (могут оставаться пустыми).
voyage_sub_data.xlsx (Вспомогательная таблица) — хранит связанные сопутствующие параметры рейсов и этапов.

Основные числовые поля базы данных:
№ п/п — Уникальный порядковый номер записи (автоинкремент).
Год — Год проведения геофизического рейса.
№ рейса — Официальный номер экспедиции.
№ этапа рейса — Номер конкретного этапа внутри экспедиции.
Номер диска — Физический или цифровой номер носителя информации.
Инвентарный номер диска — Учетный номер материального носителя в архиве.

Примечание: Все текстовые справочники внутри программы реализованы в виде фиксированных списков (List), что исключает опечатки при вводе.

🔒 Безопасность кода и валидация
Программа устойчива к ошибкам человеческого фактора благодаря встроенной функции контроля типов. 
Все передаваемые параметры в процедурах обработки данных проходят обязательную валидацию через конструкцию isinstance(). 
Если вместо числового инвентарного номера будет введена строка, система заблокирует сохранение и уведомит об ошибке, 
предотвращая порчу Excel-файла.
