•	Суть: Десктопное приложение на Python (Tkinter + Pandas) для учета научно-исследовательских геофизических рейсов.
•	Интерфейс: Многовкладочный (Tab-based) с цветовым выделением кнопок.
•	БД: Файл voyage_data.xlsx из 20 полей. Числовые поля: № п/п, Год, № рейса, № этапа рейса, Номер диска, Инвентарный номер диска.
•	Особые условия кода: Обязательна проверка типов передаваемых параметров в процедурах (isinstance). Справочники сделаны в виде списков. Поля не обязательны к заполнению. Все повторяющиеся функции вынесены в helpers.py.
•	Текущий статус: Просмотр, поиск, редактирование, удаление, создание по шаблону и бекап полностью работают.
